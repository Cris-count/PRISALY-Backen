# BD-005.2 — schema reference (authorized diagram)

Source: team ER diagram PDF (21 tables). M1 implements only the identity subset in JPA until official Flyway V001–V009 are restored.

## M1 tables (implemented in this branch)

| Table | Columns |
| --- | --- |
| Rol | idRol int, nombre varchar(30), descripcion text |
| Permiso | idPermiso int, codigo varchar(100), nombre varchar(100), descripcion text |
| Usuario | idUsuario uuid, idRol int, nombre varchar(150), correo varchar(255), passwordHash varchar(255), estado varchar(20), fechaCreacion timestamptz, fechaActualizacion timestamptz |
| UsuarioPermiso | idUsuario uuid, idPermiso int, habilitado boolean, idAdministradorAsignador uuid, fechaAsignacion timestamptz |

Rules from baseline: one principal role via `Usuario.idRol`; no Docente/Administrador/RolPermiso tables; individual permissions via `UsuarioPermiso`.
