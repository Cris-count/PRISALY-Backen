# Migraciones

Las migraciones se generan cuando existan el framework y el modelo físico conciliado con Backend.

BD-004 (16 tablas) y BD-005.1 (candidato de 17 tablas) son referencias de modelo. No son un esquema aplicado. `EnvioCorreo` pertenece al candidato BD-005.1 y no es una tabla definitiva.

Los DBML conciliados se ubican en `database/models/`.
